# Thema-instellingen N°98 Maps (Horizon)

Deze bestanden zijn in het thema "N°98 Maps (fixed)" gezet:

- `settings_data.json` → `config/settings_data.json`: papier/inkt-kleuren van
  de site, het N°98 Maps-logo (bestand `n98-maps-logo.png` in Shopify Files)
  en rechte hoeken voor knoppen, velden en kaarten.
- `header-group.json` → `sections/header-group.json`: aankondiging, logo in
  het midden, menu `n98-maps-main`, geen land/taal-kiezer.
- `footer-group.json` → `sections/footer-group.json`: alleen copyright en
  beleidslinks (de nieuwsbrief zit al in de homepage-sectie).
